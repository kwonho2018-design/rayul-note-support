# RAYUL NOTE Support

This public repository provides support and privacy information for the RAYUL NOTE iOS app.

## Support

For app support, bug reports, or privacy questions, use the Issues tab in this public support repository or the support contact shown on the RAYUL NOTE App Store product page. Do not post private notes, photos, audio files, backup files, or other personal information publicly.

## Common Checks

- If iCloud sync is enabled, confirm that the same Apple ID and iCloud Drive are active on each device.
- If camera, microphone, location, calendar, reminders, or local network features do not respond, check iOS Settings > Privacy & Security and allow the requested permission for RAYUL NOTE.
- Backup and restore files are user controlled. Keep encrypted backup passwords private.
